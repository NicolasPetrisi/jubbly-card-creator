If you need more template images, such as those used for talents and spells, then add a colored box to the area you want
removed using an image editor, such as "https://www.canva.com/photo-editor/". Then use go to the site
"https://onlinepngtools.com/create-transparent-png" and have the specific color code for the box you just added made
transparent.

A good page for upscaling images that was used:
"https://www.upscale.media/".
